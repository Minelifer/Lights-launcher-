# Light Launcher

Лёгкий лаунчер для Android TV и смарт-приставок: один экран, сетка приложений, управление пультом. APK весит около 150 КБ, из зависимостей только RecyclerView.

## Возможности
- Главный экран: сверху кнопка «Все приложения», дата и часы (формат 12/24 ч берётся из системы), ниже избранные приложения цветными плитками.
- «Все приложения»: полный список, число колонок подстраивается под ширину экрана. Кнопка «На главный» или Back возвращают на главный экран, Home тоже.
- Избранное: удерживайте OK (долгое нажатие) на приложении, чтобы добавить его на главный экран или убрать. В полном списке избранные подсвечены жёлтым названием.
- Индикатор ОЗУ в шапке: занято и всего, полоска зелёная, жёлтая от 70% и красная от 85%. Обновляется раз в 3 секунды, пока лаунчер на экране.
- Для ТВ-приложений показывается их баннер, для остальных иконка.
- Список обновляется сам при установке, обновлении и удалении приложений.
- Плитка «Настройки», если системные настройки не попали в список сами.
- На главном экране кнопка «Назад» игнорируется, лаунчер не закрывается.

## Сборка
Локально (нужны JDK 17 и Android SDK):

```
gradle assembleRelease
```

APK лежит в `app/build/outputs/apk/release/`. В GitHub Actions APK собирается при каждом пуше в `main` и доступен в артефактах запуска.

## Обновление без удаления
Все сборки подписываются одним и тем же ключом, а номер версии (`versionCode`) растёт с номером запуска в Actions, поэтому новую сборку можно ставить прямо поверх старой.

- По умолчанию используется общий ключ `app/ci-debug.keystore`. Он лежит в репозитории, секретов в нём нет, и для личного лаунчера этого достаточно.
- Если нужен собственный ключ, подпись берётся из секретов репозитория (Settings → Secrets and variables → Actions):
  - `KEYSTORE_BASE64`: ключ в base64 (`base64 -w0 release.jks`)
  - `KEYSTORE_PASSWORD`: пароль хранилища
  - `KEY_ALIAS`: имя ключа
  - `KEY_PASSWORD`: пароль ключа

  Создать ключ: `keytool -genkeypair -v -keystore release.jks -alias lightlauncher -keyalg RSA -keysize 2048 -validity 10000`. Файл `release.jks` в репозиторий не добавляйте и храните копию: потеряете ключ, и обновить приложение у пользователей уже не получится.

Смена ключа подписи (например, с общего на свой) требует один раз удалить установленную версию.

## Посмотреть на телефоне
Лаунчер появляется в списке приложений как обычная программа (вид в ландшафте, поверните телефон). Чтобы увидеть его как домашний экран, назначьте его в настройках системы: «Приложения по умолчанию» → «Домашний экран» (название зависит от оболочки). Вернуть прежний лаунчер можно там же.

## Установка на ТВ
```
adb connect <IP-ТВ>
adb install -r app-release.apk
```

Выбор домашним экраном зависит от прошивки. На части устройств система спрашивает при нажатии Home, на других назначить лаунчер можно только через настройки или adb.
