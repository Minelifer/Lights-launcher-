# Light Launcher

Лёгкий лаунчер для Android TV и смарт-приставок: один экран, сетка приложений, управление пультом. APK весит около 150 КБ, из зависимостей только RecyclerView.

## Возможности
- Рабочий стол: сверху часы и дата (формат 12/24 ч берётся из настроек системы), ниже сетка приложений, фон с мягким градиентом.
- Сетка приложений, число колонок подстраивается под ширину экрана.
- Для ТВ-приложений показывается их баннер, для остальных иконка.
- Список обновляется сам при установке, обновлении и удалении приложений.
- Плитка «Настройки», если системные настройки не попали в список сами.
- Кнопка «Назад» на главном экране игнорируется.

## Сборка
Локально (нужны JDK 17 и Android SDK):

```
gradle assembleRelease
```

Без ключа подписи сборка получит debug-подпись. APK лежит в `app/build/outputs/apk/release/`.

В GitHub Actions APK собирается при каждом пуше в `main` и доступен в артефактах запуска.

## Постоянная подпись
Чтобы новые версии устанавливались поверх старых, подписывайте APK одним и тем же ключом.

1. Создайте ключ:

   ```
   keytool -genkeypair -v -keystore release.jks -alias lightlauncher -keyalg RSA -keysize 2048 -validity 10000
   ```

2. Закодируйте его в base64: `base64 -w0 release.jks` (на macOS: `base64 -i release.jks`).
3. В репозитории откройте Settings → Secrets and variables → Actions и добавьте секреты:
   - `KEYSTORE_BASE64`: строка из шага 2
   - `KEYSTORE_PASSWORD`: пароль хранилища
   - `KEY_ALIAS`: `lightlauncher`
   - `KEY_PASSWORD`: пароль ключа

Сам файл `release.jks` в репозиторий не добавляйте и храните копию в надёжном месте: потеряете ключ, и обновить приложение у пользователей уже не получится.

## Посмотреть на телефоне
Лаунчер появляется в списке приложений как обычная программа (вид в ландшафте, поверните телефон). Чтобы увидеть его как домашний экран, назначьте его в настройках системы: «Приложения по умолчанию» → «Домашний экран» (название зависит от оболочки). Вернуть прежний лаунчер можно там же.

## Установка на ТВ
```
adb connect <IP-ТВ>
adb install -r app-release.apk
```

Выбор домашним экраном зависит от прошивки. На части устройств система спрашивает при нажатии Home, на других назначить лаунчер можно только через настройки или adb.
